تحديث متكامل للموقع Diva Suez Store (v12):
----------------------------------------
التعديلات المرفقة في الملف:
1. معرض الصور وتفاصيل المنتجات (Modal + Zoom + Prev/Next):
   - إمكانية تكبير وتصغير الصور (Zoom In / Out / Reset / Fullscreen).
   - إمكانية فتح تفاصيل أي منتج وقراءة الوصف كاملاً والتقليب بين صوره.

2. تصفية العطور (رجالي / حريمي / الكل):
   - إضافة فلاتر سريعة لتصفح العطور حسب الفئة.

3. قسم الإعلانات (واجهة الموقع + لوحة الأدمن):
   - قسم جذاب للإعلانات على واجهة الموقع الرئيسية (يتم جلب الإعلانات تلقائياً).
   - لوحة الأدمن (admin.html + api/ads.js + api/admin.js): إمكانية إضافة إعلانات جديدة برفع الصورة وتحديد العنوان والوصف وحذف الإعلانات الحالية.

طريقة الرفع على GitHub / Vercel:
1. فك ضغط هذا الملف ZIP على جهازك.
2. قم بنسخ جميع الملفات والمجلدات إلى المجلد الرئيسي لمشروعك (أو ارفع الملفات عبر GitHub Upload).
3. قم بعمل Commit & Push للـ Repository.
4. انتظر حتى يكتمل التحديث تلقائياً على Vercel.
